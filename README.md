# 光年闲鱼助手 v1.2.10

- 接入 Ant Design 6.7.0，统一按钮、输入框、下拉候选及商品多选，采用蓝紫深浅主题；支持下拉搜索、键盘操作和弹窗内选择。
- 重新组织工作台与大屏：四项核心指标、资源概况、趋势、调用、成本售后和插件数据分层展示，保留日期范围、刷新、运营处置与完整报表。
- 卡密、套餐、题库、服务与调用记录改为多维详细列表；自动化规则、账号、订单、商品、库存、模板、团队及通知列表补齐业务字段，减少逐行重复说明。
- 在线聊天对齐会话、消息、买家资料三栏布局，统一消息气泡和输入工具；保留备注、快捷回复、图片和商品卡片，修正手机会话删除按钮及未读角标重叠。
- 主列表独立滚动，分页固定悬浮在视口底部，默认 50 条，支持 25 / 50 / 100 条、页码直达和跳页；保留实际总量、筛选及翻页后选择清理，手机仍可切换每页数量。
- 侧栏明确展示“版本管理 · 当前版本”，保留自动 / GitHub / CNB 来源、真实下载进度、升级确认、历史详情及回退确认。更新安装包后刷新页面即可使用新界面。
- 同步更新管理端操作手册、前端说明、部署与发布说明及逐项功能核对。接口、数据库结构、自动发货顺序、卡密权益、权限和冻结的验证码流程保持原有契约。
